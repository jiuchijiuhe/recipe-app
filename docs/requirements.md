# 开发需求文档

## 项目名称
每日食谱推荐（RecipeApp）

## 项目目标
做一个手机上就能用的食谱推荐网站，帮助用户根据现有食材、口味偏好、用餐人数，快速找到想做的菜，并提供详细的做菜教程。

## 目标用户
- 每天发愁"吃什么"的普通人
- 想根据冰箱现有食材做菜的居家用户
- 关注减脂/健康饮食的人群
- 喜欢收藏食谱的新手厨师

## 功能需求

### F1 — 每日推荐
- 打开首页随机推荐 3 道菜
- 用户可以点击「换一批」刷新推荐
- 推荐基于季节和时段（早餐/午餐/晚餐）

### F2 — 食材筛选
- 提供常用食材标签供用户多选（鸡蛋、西红柿、猪肉、豆腐等）
- 根据已选食材，筛选出能用这些食材做的菜
- 按匹配度从高到低排序（食材匹配越多越靠前）

### F3 — 做菜教程
- 食材清单（主料 + 调料，含用量）
- 分步骤图文教程
- 每步配有文字说明
- 烹饪时间和难度等级

### F4 — 菜系/类型筛选
- 分类：家常菜、川菜、粤菜、减脂餐、汤煲、面食等
- 单选切换，选中某类后只显示该类食谱

### F5 — 用餐人数筛选
- 一人食：快速简单，分量刚好
- 家庭聚餐：3-4 人份，菜品更丰富

### F6 — 收藏食谱
- 食谱详情页点击收藏按钮
- 收藏的食谱在「收藏」页展示
- 支持取消收藏
- 数据存手机本地（浏览器 LocalStorage）

### F7 — 搜索菜品
- 顶部搜索框，支持输入中文菜名
- 模糊搜索，匹配菜名中的关键词

### F8 — 智能推荐排序
- 综合食材匹配度、菜系偏好、季节适宜度排序
- 最近做过的菜降低权重，避免重复推荐

## 非功能需求
- 移动端优先，适配手机屏幕
- 加载速度快，纯前端无后端
- 无需注册登录即可使用
