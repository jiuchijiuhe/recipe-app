# 技术方案说明

## 整体架构

```
┌─────────────────────────────────┐
│       用户手机浏览器              │
├─────────────────────────────────┤
│  Vue 3 单页应用 (SPA)            │
│  ├── 路由: vue-router           │
│  ├── UI: Vant 4 (移动端组件库)   │
│  ├── 状态: Vue reactive         │
│  └── 持久化: LocalStorage       │
├─────────────────────────────────┤
│  纯前端，无后端服务器             │
│  所有食谱数据内置在 JSON 文件中   │
└─────────────────────────────────┘
```

## 技术选型及理由

| 技术 | 版本 | 选型理由 |
|------|------|----------|
| Vue 3 | 3.5+ | 中文文档丰富，上手简单，Composition API 清晰 |
| Vite | 8.x | 开发服务器极快，构建快，Vue 官方推荐 |
| Vant UI | 4.x | 优秀的中文移动端组件库，组件齐全 |
| vue-router | 4.x | Vue 官方路由，页面切换标配 |

## 推荐算法设计

```
总分 = 
  食材匹配分(0-50)  → 用户选中的食材中，食谱用到了几种
+ 菜系匹配分(0-20)  → 用户选择的菜系是否匹配
+ 人数匹配分(0-10)  → 食谱份数与用户选择是否一致
+ 季节适宜分(0-10)  → 夏天偏凉菜/轻食，冬天偏汤煲/炖菜
- 重复惩罚(0-20)    → 最近 7 天做过/看过的菜扣分

按总分从高到低排序
```

## 存储方案

- 收藏数据：`localStorage.setItem('favorites', JSON.stringify([id1, id2, ...]))`
- 浏览历史：`localStorage.setItem('history', JSON.stringify([...]))`
- 无需后端数据库，数据全在用户手机浏览器中

## 部署方案

- 开发：`npm run dev`，本地运行，手机同 WiFi 下可访问
- 部署：Vercel / Netlify 免费部署，获得公开网址
