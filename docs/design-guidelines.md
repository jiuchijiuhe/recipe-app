# 设计规范

## 设计原则
- 移动端优先：以手机屏幕（375-414px 宽度）为设计基准
- 简洁温馨：食物主题，暖色调为主
- 大字体大按钮：方便操作，减少误触

## 颜色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#5B9BD5` | 淡蓝色，用于按钮、高亮、图标、步骤号 |
| 浅蓝背景 | `#EBF5FB` | 极淡蓝，用于缩略图背景、标签、提示框 |
| 辅助色 | `#87CEEB` | 天蓝，用于菜系标签等 |
| 页面背景 | `#F0F4F8` | 淡蓝灰背景 |
| 卡片背景 | `#FFFFFF` | 白色卡片 |
| 主文字 | `#323233` | 深灰，Vant 默认 |
| 次要文字 | `#969799` | 灰色说明文字 |

## 字体

| 层级 | 大小 | 粗细 | 用途 |
|------|------|------|------|
| 大标题 | 24px | bold | 页面主标题 |
| 标题 | 18px | bold | 食谱名称 |
| 正文 | 16px | normal | 步骤说明 |
| 说明 | 14px | normal | 食材用量、时长 |
| 标签 | 12px | normal | 分类标签 |

## 间距

| 元素 | 间距 |
|------|------|
| 页面边距 | 16px |
| 卡片间距 | 12px |
| 内容区上下间距 | 16px |
| 按钮高度 | 44px（最小触摸目标） |

## 圆角

| 元素 | 圆角 |
|------|------|
| 卡片 | 12px |
| 按钮 | 8px |
| 标签 | 4px |
| 图片 | 8px |

## 组件使用规范

- 底部导航：`van-tabbar`，固定 3 个 Tab（首页/筛选/收藏）
- 搜索框：`van-search`，圆角搜索框
- 卡片：`van-card`，展示食谱缩略图+名称+标签
- 标签：`van-tag`，显示菜系、难度、时长
- 按钮：`van-button`，主操作用主色，次要操作用白色边框
- 网格：`van-grid`，分类入口展示
- 弹出层：`van-popup`，食材筛选面板
- Toast：`van-toast`，操作反馈

## 图标

使用 Vant 内置图标库，前缀 `van-icon-`：
- 首页：`home-o`
- 搜索：`search`
- 收藏：`star-o` / `star`（已收藏状态）
- 时间：`clock-o`
- 难度：`chart-trending-o`
- 人数：`user-o`
- 返回：`arrow-left`
